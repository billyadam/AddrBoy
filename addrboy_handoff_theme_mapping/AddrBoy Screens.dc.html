ADDRBOY · WALLET ADDRESS BOOK · FIELD GUIDE THEME · 240×160 SHOWN AT 2×
A standalone app with no link to AuthBoy. It borrows the Field Guide look (header, panels, footer, selection), so the same set of themes (Net Link, Pocket LCD, Phosphor) can be ported by swapping palettes. It works in two panels. Pick a wallet, then a network, then show the QR code. Wallet type uses a square badge (C, H, E) and network uses a round coin, so the two never get confused.

NOTES FOR THE BUILD
· Button map: A moves forward (wallet → network → QR) and B moves back. L and R cycle the header filter pill. Up and down on the QR screen switch to the wallet's next network, so you never leave the QR. START opens the menu, which includes Settings and Theme.
· The QR panel is 110 px square. At 3 px per module it fits up to version 4 (33×33, enough for a 66-character SUI or APT address) with a 2-module quiet zone. EVM addresses use version 3 (29×29). Always draw the QR as pure black on white, whatever the theme. The QR in screen 03 is a placeholder pattern.
· The digits8 font is uppercase only, but Base58 addresses (BTC legacy and SOL) are case sensitive. You need an extra 5×7 font with lowercase and a 6 px advance (Press Start 2P stands in for it here). Split addresses into groups of 4 so they're easier to compare by eye.
· Check each network's address format as it's typed, and check the checksum on save (bech32 or Base58Check for BTC, EIP-55 for EVM, length for SOL, SUI and APT). Show a red counter if the address is invalid.
